# 【香山双周报 28】20230515 期

欢迎来到我们的双周报专栏。本次是香山双周报专栏的第 28 期，我们将通过这一专栏，定期介绍香山的开源进展，希望与大家共同学习，一起进步。近期，昆明湖研发稳步推进，前端添加了预取到 L1 的 FDIP 预取机制，修复一些性能  bug；后端继续推进向量扩展实现，实现了检查点恢复等机制；访存单元优化了组件性能并推进向量通路开发；缓存系统修复了若干多核 bug 并推进 CHI 协议支持。欢迎大家通过公众号后台留言的方式与我们交流！

<!-- more -->
## 近期进展

### 前端

* 添加 FDIP 预取到 L1I 功能
* 修复 ITTAGE 遗漏基础预测 bug

### 后端流水线

* vset 功能单元添加 vill 输出
* 检查点恢复重命名表的初版实现完成

### 访存单元

* LQ 拆分 code review 与进一步优化
* 继续实现和调试向量通路
* 确认 sbuffer 的性能 bug 并修复
* LQ 入队算法改进
* 评估 Linux 开启 Transparent Huge Pages 的收益

### 缓存系统

* 运行单核 SPEC 测试程序，性能相较南湖缓存有正向收益
* 修复了若干双核情况下的 bug
* 完成基于 CHI 协议改造的任务分解，开始进行细节分析
* 在 CHI 验证框架中设计 hazard 场景处理流程

## 后记

香山开源处理器正在火热地开发中，新的功能与新的优化在持续添加中，我们将通过香山双周报专栏定期地同步我们的开源进展。感谢您的关注，欢迎在后台留言与我们交流！
