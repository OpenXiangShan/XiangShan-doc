# 【香山双周报 16】20220905 期

欢迎来到我们的双周报专栏。本次是香山双周报专栏的第 16 期，我们将通过这一专栏，定期介绍香山的开源进展，希望与大家共同学习，一起进步。欢迎大家通过公众号后台留言的方式与我们交流！

<!-- more -->
## 近期进展

### 前端

* **南湖优化**

    * BPU

        * 复制 s2、s3 阶段寄存器以解决高扇出问题
        * 复制 RAS 栈顶项、预测 bundle is\_minimal 解决到 npc 路径高扇出
        * 复制 BPU update 信号供不同预测器更新使用
        * 复制预测器开关控制 enable 信号初始化寄存器以解决仿真不定态问题
        * 重构 Update 通道 Bundle 以解决未使用信号对测试造成干扰问题
        * uBTB 改为 32 项全相连以解决 SRAM 到 SRAM 路径并针对扇出问题复制一份

    * FTQ

        * 复制 last\_cycle\_bpu\_in 等信号解决高扇出问题

    * ICache

        * 复制读请求信号以解决 ICache SRAM 高扇出问题
        * 锁存 data SRAM 结果后送入 CacheOP 以解决 SRAM 高扇出到 CacheOP 问题
        * targetFault 生成逻辑前移以解决 Predecode 模块到终点线延迟过高问题
        * 容量下调到 64KB

### 后端流水线

* **昆明湖设计**

    * 浮点单元

        * 2 种实现方式 (低延迟高面积和高延迟低面积) 的支持 widening 功能的 fadd 已完成

### 访存单元

* **南湖时序收尾**

    * 优化 LSU 的内部逻辑，消除 DCache data SRAM 到 load queue 的非必要路径
    * 调整 LSU uncache 相关逻辑以方便 floorplan
    * 优化 DCache data SRAM 的读写时序
    * DCache 下调到 64KB，后端优化 floorplan 后不再是关键路径

### 缓存系统

* 昆明湖设计规划：3 项主体任务

    * 编写新版 L2：正在进行主流水线框架的搭建
    * 改进当前 L3：简化代码，并计划形式化描述当前 Transaction 处理策略
    * 预取、替换与性能调优

## 后记

香山开源处理器正在火热地开发中，新的功能与新的优化在持续添加中，我们将通过香山双周报专栏定期地同步我们的开源进展。感谢您的关注，欢迎在后台留言与我们交流！
