# 【香山双周报 27】20230424 期

欢迎来到我们的双周报专栏。本次是香山双周报专栏的第 27 期，我们将通过这一专栏，定期介绍香山的开源进展，希望与大家共同学习，一起进步。近期，昆明湖研发稳步推进，前端去除了 ICache 硬件一致性支持，修复一些性能 bug；后端基本完成乱序调度重构，实现了重命名表快照恢复等机制；访存单元完成向量 load 通路，优化了组件性能；缓存系统正在进行性能调优并实现了一些 CHI 总线组件，接入新预取器。欢迎大家通过公众号后台留言的方式与我们交流！

<!-- more -->
## 近期进展

### 前端

* 修复 FTQ 满时 BPU 入队效率减半问题
* 修复 ITTAGE 更新信号与 TAGE 不同步导致互相阻塞问题
* ICache 去除一致性支持并添加 fencei 指令处理机制

### 后端流水线

* 实现重命名表的快照恢复机制
* 基本完成乱序调度部分的重构工作，实现发射后读寄存器堆
* 实现 FuBusyTable，能够在 IQ 指令选择时避免可流水 Exu 于写回时刻仲裁导致阻塞

### 访存单元

* 利用 SQ 代替 LFST，优化 MDP
* 实现 oracle MDP 框架
* 进行性能评估：

    * 评估 WPU 的性能
    * 评估 Store 预取以及自定义总线的性能

* 优化 Sector tlb
* 向量 load 通路代码完成，进行调试

### 缓存系统

* 进行性能调优：

    * 成功移除请求的 set 阻塞逻辑，并优化请求仲裁逻辑，确认有正向收益
    * 使用模拟器进行 refill 优化的性能收益评估

* 实现了用来驱动 CHI-Test 测试框架的 CHI-Master
* 正在开发 CHI 总线桥，目前可以处理最基础的请求
* 成功接入 IPCP Prefetcher

## 后记

香山开源处理器正在火热地开发中，新的功能与新的优化在持续添加中，我们将通过香山双周报专栏定期地同步我们的开源进展。感谢您的关注，欢迎在后台留言与我们交流！
