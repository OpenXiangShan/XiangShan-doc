# 【香山双周报 18】20221017 期

欢迎来到我们的双周报专栏。本次是香山双周报专栏的第 18 期，我们将通过这一专栏，定期介绍香山的开源进展，希望与大家共同学习，一起进步。欢迎大家通过公众号后台留言的方式与我们交流！

<!-- more -->
## 近期进展

### 前端

* ICache

    * RTL 版本的 FDIP 指令预取正在进行调试，目前已完成初步版本
    * 去除 Tilelink 一致性维护逻辑改为软件 fence.i 维护
    * 增加 multiple-hit 错误的验证信号

* IFU

    * MMIO 取指等待上一取指块提交再发送请求，避免 MMIO 总线上的推测执行

* BPU

    * Oracle 预测器修复性能 bug

### 后端流水线

* 南湖流片

    * 为 wfi 指令添加默认 timeout (1M cycles)，wfi 指令会在收到中断或达到 timeout 时，执行结束
    * 定位通过 JTAG 接口调试时的一些 bug，正在修复
    * 修复在 ROB 状态位未初始化时，接受中断导致的 X 态传播问题

* 昆明湖设计 & 实现

    * 开始重构保留站，计划改为发射后读寄存器堆
    * 完成向量浮点加法器的所有功能和流水级划分

        * 支持 f16, f32, f64 三种数据类型
        * 支持 widening 运算

### 访存单元

* 南湖验证

    * 修复 load queue 没有判断取消的当拍的状态导致 CSR 出现错误的问题，在 FPGA 上通过了之前出错的测试点
    * 为 dcache alias 问题添加新的单元测试

* 昆明湖设计

    * 讨论昆明湖访存单元的优化方案
    * 同步部分时序修改到主分支

* 杂项

    * 完成 Memblock, data cache, MMU 的验证文档

### 缓存系统

* 南湖验证

    * 增强针对 DMA 的单元验证

* 昆明湖设计

    * 正在构建 Acquire Miss 和 Release 通路
    * 实现完善 CMO 操作的控制逻辑

## 后记

香山开源处理器正在火热地开发中，新的功能与新的优化在持续添加中，我们将通过香山双周报专栏定期地同步我们的开源进展。感谢您的关注，欢迎在后台留言与我们交流！
