# 【香山双周报 15】20220815 期

欢迎来到我们的双周报专栏。本次是香山双周报专栏的第 15 期，我们将通过这一专栏，定期介绍香山的开源进展，希望与大家共同学习，一起进步。欢迎大家通过公众号后台留言的方式与我们交流！

<!-- more -->
## 近期进展

### 前端

* **南湖优化**

    * 为 TAGE-SC 预测器使用的 SRAM 增加写 bypass 逻辑以解决不定态问题
    * 修复 TAGE 中 resp\_invalid\_by\_write 信号判断条件
    * 使用复制涉及寄存器的方法解决 ICache 高扇出问题
    * 修复预测块预测最后两字节跳转而预测错误后该标志位未能刷掉的 bug

### 后端流水线

* **南湖优化**

    * 为 fma 指令的中间结果添加寄存器，以优化时序
    * 为重定向信号添加寄存器，以减小扇出
    * 用 ParallelMux 替换 Mux1H，保证 deqRespSucc 仅在 deq.valid 时置位的同时，减少一个逻辑与门
    * 为 fdivSqrt 单元添加分立的数据选择寄存器，以减小选通 valid 信号的扇出
    * 减小 InputBuffer 中 emptyVec 信号的扇出
    * 优化保留站中 age 矩阵的更新逻辑

* **昆明湖探索**

    * 优化了浮点加法器的时序，之后继续开展其他浮点单元的优化改进

### 访存单元

* **南湖优化**

    * 为 DTLB 的 Victim Write 信号添加一拍延迟，并增加 bypass 逻辑，优化写时序
    * 为 L1 TLB 的刷新和 VmEnable 信号添加寄存器，减少扇出
    * 为 L2 TLB 的刷新和回填信号添加寄存器，减少扇出
    * 为 load queue，store queue 的数据写入增加一拍延迟，减少扇出
    * 优化 load queue，store queue 更新的控制信号，减少扇出
    * 减少 dcache 主流水线控制信号，手动复制必要的寄存器以减少扇出
    * 优化 dcache writeback queue meta 更新逻辑，减少不必要的更新并减少扇出
    * 优化 dcache meta array，writeback queue，miss queue 的数据读写逻辑，为写入增加一拍延迟以减少扇出
    * 优化 sbuffer data 和 mask 的写入逻辑，为写入增加一拍延迟以减少扇出
    * 优化 dcache 指令和错误处理相关的扇出

### 缓存系统

* **南湖优化**

    * 优化 L3 的 SRAM 读写逻辑时序，在某些情况下会增加一拍的延迟

* **安排昆明湖设计规划，确定缓存主体架构**

    * L2

        * 采用类 L1 的设计思路，设立主流水线，淘汰粗放的按 Set 阻塞
        * 控制逻辑与 L1 紧密耦合
        * 优化预取算法、替换算法、MSHR 分配策略等

    * L3

        * 重新构思并形式化 Non-inclusive 策略的状态转移
        * 优化替换算法、MSHR 分配和任务仲裁等

### 产品化改造

* **从本期开始，南湖架构更为细节的设计文档编写工作逐步展开**

    * 文档覆盖香山现有前端、后端、访存、缓存四大模块
    * 文档包含功能描述、结构设计图、接口定义与时序、状态机等部分

## 后记

香山开源处理器正在火热地开发中，新的功能与新的优化在持续添加中，我们将通过香山双周报专栏定期地同步我们的开源进展。感谢您的关注，欢迎在后台留言与我们交流！
