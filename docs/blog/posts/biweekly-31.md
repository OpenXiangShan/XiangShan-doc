# 【香山双周报 31】20230718 期

欢迎来到我们的双周报专栏。本次是香山双周报专栏的第 31 期，我们将通过这一专栏，定期介绍香山的开源进展，希望与大家共同学习，一起进步。近期，昆明湖研发稳步推进，后端继续推进 V 扩展和 H 扩展；访存继续推进向量访存主线合入和各个性能优化工作；缓存系统推进请求逻辑优化并做了一些性能探索。欢迎大家通过公众号后台留言的方式与我们交流！

<!-- more -->
## 近期进展

### 前端

* 修复预译码边界情况处理错误
* 调试预测器参数，暂无显著效果

### 后端流水线

* IQ 推测唤醒：添加部分推测唤醒通路，修复部分 bug，可以启动 Linux
* Move 指令消除：合入新版 ME 设计，优化时序和面积
* H 扩展：合入 NEMU 对 H 扩展 1.0 版本的支持
* 向量扩展：完成合入 Vperm 和 Vred
* vfalu 集成验证：已支持 vv 和 vf、lmul1248、vm 逻辑等

### 访存单元

* 功能

    * 重构 Load/Store Unit 代码，完成 Memblock 接口信号封装
    * 添加 Hybrid unit，给 load store 共用
    * 修复 load store 流水线的部分 bug
    * 合并 128 bits 通路，调试性能下降的问题

* 性能

    * 完成 Sbuffer 加入动态阈值机制，针对性优化 Ibm
    * 完成 bank conflict 的针对读写 bank 的细粒度优化
    * 完成 MDP 代码，并修复其性能评估时的若干问题
    * 完成 L1 stream 预取以及 L1 L2 多级预取和动态调控机制，性能调试中
    * 进行 TLB filter 优化
    * 测试 stlf latency，与其他处理器对比，对应修改 Load Replay Queue

* 时序

    * 针对新版 master 代码访存部分进行时序评估，并解决其中部分时序问题

### 缓存系统

* 功能开发

    * 继续实现请求处理逻辑的优化，完成收到重填请求后再计算替换块并释放的机制，目前已通过单核带 alias 的 tl-test，代码正在合入主线
    * 修复了部分一致性相关的 bug
    * 针对新版 CPL2 代码进行时序评估，并解决了部分时序问题
    * 在 MainPipe 模块和总线中添加了更多信息的 DB 记录，并在 tl-test 中也添加了 ChiselDB 的支持

* 性能前瞻

    * 分析 CMC 和 SMS 预取器的退避策略，在模拟器上通过 archdb 微观分析预取数据块的行为，实现 CMC 预取的存储结构，并测试了不同替换策略对预取性能的影响
    * 完成 CHI-Test 验证框架 RN-F 端和 ICN Agent 的代码实现，并通过了  RN-F 和 ICN 的联合测试
    * 针对 DRRIP 替换策略进行了优化，并进行性能测试

## 后记

香山开源处理器正在火热地开发中，新的功能与新的优化在持续添加中，我们将通过香山双周报专栏定期地同步我们的开源进展。感谢您的关注，欢迎在后台留言与我们交流！
