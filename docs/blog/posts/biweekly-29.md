# 【香山双周报 29】20230529 期

欢迎来到我们的双周报专栏。本次是香山双周报专栏的第 29 期，我们将通过这一专栏，定期介绍香山的开源进展，希望与大家共同学习，一起进步。近期，昆明湖研发稳步推进，前端添加了分支历史检查工具；后端继续推进向量扩展实现，实现了通用 Mgu；访存单元优化了组件性能并推进向量通路开发；缓存系统修复了若干多核 bug 并继续推进 CHI 协议支持。欢迎大家通过公众号后台留言的方式与我们交流！

<!-- more -->
## 近期进展

### 前端

* 实现分支历史在线检查工具

### 后端流水线

* 支持向量整型可流水功能单元，通过集成测试
* 设计实现通用 Mgu，用于向量运算的 agnostic 处理和 vd 旧数据合并

### 访存单元

* LQ 拆分架构合入主线
* 完善 LSU 部分的 TopDown 框架
* 继续修复写合并缓冲替换算法的问题
* 继续修复 store miss MLP 的问题
* 继续实现并测试 dcache data array 读写冲突细粒度化判断
* 继续实现并测试 dcache cacheline 级别分 bank 的设计
* 更新适配 LQ 拆分架构的 MDP 实现

### 缓存系统

* 解决了若干双核场景下的 bug，目前 CPL2 已成功合入香山主线
* CPL2 添加 Topdown 性能计数器，以进行香山全系统的性能分析
* 利用模拟器评估多种替换策略的性能
* 完成 CHI-Test 测试框架 Slave Agent 的实现

## 后记

香山开源处理器正在火热地开发中，新的功能与新的优化在持续添加中，我们将通过香山双周报专栏定期地同步我们的开源进展。感谢您的关注，欢迎在后台留言与我们交流！
