# 【香山双周报 20】20221114 期

欢迎来到我们的双周报专栏。本次是香山双周报专栏的第 20 期，我们将通过这一专栏，定期介绍香山的开源进展，希望与大家共同学习，一起进步。欢迎大家通过公众号后台留言的方式与我们交流！

<!-- more -->
## 近期进展

### 前端

* 南湖验证

    * 修复 MMIO 取指通路误冲刷 IFU f3 问题，允许 FPGA 平台从 Flash 取指

* 昆明湖开发

    * 迁移南湖分支更改到 master 分支
    * FDIP 预取器性能调优

### 后端流水线

* 昆明湖开发

    * 全功能 FMA 模块的流水线划分基本完成，正在测试 corner case
    * VPU 架构设计即将完成

### 访存单元

* 昆明湖设计

    * 推进 LSQ based replay 与 StoreSet 优化的代码工作

### 缓存系统

* 南湖验证

    * 推进 DMA 调试，已成功从 nfs 启动 Linux，正在调试双核 nfs 启动的引导镜像
    * 推进 FPGA 上 SRAM 半频的调试

* 昆明湖设计

    * 推进新版 L2 Cache 的 MSHR、MainPipe 和 WritebackQueue 等模块的代码

### 产品化改造

* 接 openocd 及 gdb 远程调试

    * 解决了 hbreak 硬件断点设置问题
    * 解决了 DebugModule 重置核心后无法保存核心重置状态的问题
    * 现在核心连接 openocd 可以在执行第一条指令前 halt，等待调试器的命令

* 根据后端的需求修改访存单元 RTL 走线

## 后记

香山开源处理器正在火热地开发中，新的功能与新的优化在持续添加中，我们将通过香山双周报专栏定期地同步我们的开源进展。感谢您的关注，欢迎在后台留言与我们交流！
