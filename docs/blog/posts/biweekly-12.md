# 【香山双周报 12】20220627 期

欢迎来到我们的双周报专栏。本次是香山双周报专栏的第 12 期，我们将通过这一专栏，定期介绍香山的开源进展，希望与大家共同学习，一起进步。欢迎大家通过公众号后台留言的方式与我们交流！

<!-- more -->
## 近期进展

### 前端

* **修复 Frontend 各个模块的时序问题**

    * IFU 优化 cut 逻辑，ICache 的 Data select 后移一拍

### 后端流水线

* **优化译码阶段的重命名表读地址生成时序**

    * 将 lui 指令的 lsrc 选通信号移动到 dispatch 阶段
    * 将 fusion decoder 与读 rat 操作并行化

* **优化性能计数器时序**

    * 为部分性能计数器添加寄存器并流水化

* **优化整型与浮点跨域操作时序**

    * 在执行单元后添加 buffer，切断 ready 信号的反压

* **优化 freelist 时序**

    * 优化头尾指针的更新逻辑

* **后端架构设计讨论围绕指令融合、优化重命名策略和 V 拓展剩余细节展开。**
* **指令融合**

    * 对 spec06/17 在 RV64GCB 指令集上做 profiling

* **重命名优化 (方案讨论)**

    * 使用 queue 型 freelist，在 commit 时维护 arch reg 的 ref counter 与 freelist pointer
    * 使用 bit vec 型 freelist，用分组分配的方式优化时序

* **V 拓展**

    * 完成大部分算术指令的微指令拆分方案
    * 讨论读写 mask 寄存器的实现方案

        * 方案一，串行执行目的寄存器相同的 uop，将 vd 作为 uop 的源寄存器，将当前 uop 的结果与前一 uop 的结果合并后写回寄存器
        * 方案二，运算 uop 并行写入不同向量物理寄存器，添加 merge uop 合并运算结果写回寄存器
        * 方案三，添加 mask 寄存器堆 (寄存器位宽为 VLEN/8)，并做重命名，建立 v0 与 mask 寄存器堆的映射关系
        * 方案四，将 v0 当作控制寄存器，不做重命名，修改 v0 的指令阻塞后续使用 v0 的指令

    * 讨论访存 uop 拆分及控制方案

        * 以向量寄存器为粒度拆分，在 VLSU 内部控制每个 uop 的多次访存操作

### 访存单元

* **MMU 时序优化**

    * DTLB 128 项直接相连，每一项有一个 Valid 寄存器，将其分组，分两拍读，缓解时序压力
    * L2 TLB 组相联，128 组 4 路，从 SRAM 读出数据后，增加一拍，再进行 tag 比对和 ecc 检查

* **DCache 时序优化**

    * 优化 ECC 校验和 access fault 例外的生成逻辑：精确例外加拍
    * 通过加拍优化 PLRU 替换的时序，refill 时不更新替换算法
    * 放松 disable load fast wakeup 的条件

### 缓存系统

* **Inclusive 版本的 HuanCun 增加 anti-alias 功能以便接入核中**
* **限制 L3 MSHR 阻塞粒度以规避潜在的功能问题**
* **时序优化**

    * 消除通道控制器读写 DataStorage 的 ready 依赖
    * 优化 MSHR 到控制通道器的仲裁逻辑

### 杂项

* **修复仿真环境 PLIC 异常随机生成数量硬编码问题并同步到测试用例**

## 后记

香山开源处理器正在火热地开发中，新的功能与新的优化在持续添加中，我们将通过香山双周报专栏定期地同步我们的开源进展。感谢您的关注，欢迎在后台留言与我们交流！
