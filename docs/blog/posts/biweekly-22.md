# 【香山双周报 22】20230109 期

欢迎来到我们的双周报专栏。本次是香山双周报专栏的第 22 期，我们将通过这一专栏，定期介绍香山的开源进展，希望与大家共同学习，一起进步。欢迎大家通过公众号后台留言的方式与我们交流！

<!-- more -->
## 近期进展

### 前端

* FDIP 预取器 bug 修复
* 完善 ICache fencei 指令支持

### 后端流水线

* 乱序流水线部分

    * 重构译码表，避免在新增字段时修改所有指令译码信息
    * 新增向量译码表，遇到真值表过大时 QMCMinimizer 算法内存开销巨大的问题。加入全部向量指令，指定参数 Xmx=256GB 会提示内存耗尽。暂时用 ListLookUp 规避该问题。未来可能采用 EspressoMinimizer 作为真值表化简算法
    * 初步完成 vset\*指令的设计和实现

        * 将 vl 与 vtype 合并为 vconfig，通过重命名来支持乱序调度，重命名使用整型寄存器堆。vconfig 的逻辑寄存器编号为 32
        * vset\*指令的执行结果将会影响向量指令译码拆分，当前 vset\*指令都会冲刷流水线，以保证向量指令译码时可以拿到正确的 vconfig。针对 vsetvli 和 vsetivli 指令的优化设计和实现还在进行中

* 向量拓展部分

    * 实现向量有符号数 8/16/32/64 位加/减/带进位加/带进位减/进位借位的功能单元
    * 实现加法 widening 功能单元
    * 完成向量寄存器和向量 CSR 的 difftest 支持

### 访存单元

* LQ no data 架构修改合并进主分支。L1 miss 后 refill 的数据现在不再经过 Load Queue 相关结构
* dcache 路预测框架合并进主分支 (尚未启用)
* 为 PTW refill 添加了协同仿真检查

### 缓存系统

* 主流水线设计仍在 debug 中
* 实现了处理 cache alias 问题的设计，并成功通过测试
* 为测试框架 tl-test 添加了 probe 相关测试

## 后记

香山开源处理器正在火热地开发中，新的功能与新的优化在持续添加中，我们将通过香山双周报专栏定期地同步我们的开源进展。感谢您的关注，欢迎在后台留言与我们交流！
