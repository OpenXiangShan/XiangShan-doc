# 【香山双周报 21】20221205 期

欢迎来到我们的双周报专栏。本次是香山双周报专栏的第 21 期，我们将通过这一专栏，定期介绍香山的开源进展，希望与大家共同学习，一起进步。欢迎大家通过公众号后台留言的方式与我们交流！

<!-- more -->
## 近期进展

### 前端

* FDIP 预取器改进，有效降低 Cache Miss

### 后端流水线

* 完成向量浮点符号迁移、Merge、Classify 等运算单元的设计
* 保留站后读寄存器通过基础测试

### 访存单元

* 实现非阻塞的 L1 Dcache mainpipe
* 定位与解决 def-store-load-use 相关的性能问题
* 推进路预测框架的搭建
* 推进 load 指令重发机制修改
* 修复了 uncache 优化相关的问题

### 缓存系统

* 完成了 TileLink 各请求的基本数据 & 控制通路
* 正在对其进行测试，修复 bug，以及完善测试框架
* 正在设计处理数据冒险与请求嵌套相关逻辑

### 南湖项目

香山第二版（南湖）即将在明年初完成 14nm 工艺的双核芯片流片，目前我们已经完成功能与性能验证攻关，在 FPGA 上成功完成单核、双核、DMA 等多场景下的负载测试，正在进行最后的回归。我们将在南湖项目流片后分享南湖在功能、性能、物理设计等方面的信息。

* 修复 ICache prefetch entry 未加入 TileLink 总线 id 范围导致事务混淆问题
* 修复 RISC-V Debug Mode 相关功能实现
* 修复 MMU 指针位宽问题
* 修复 HuanCun 在双核场景下的若干个 bug

## 后记

香山开源处理器正在火热地开发中，新的功能与新的优化在持续添加中，我们将通过香山双周报专栏定期地同步我们的开源进展。感谢您的关注，欢迎在后台留言与我们交流！
