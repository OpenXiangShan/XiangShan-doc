# 【香山双周报 6】20211213 期

欢迎来到我们的双周报专栏。本次是香山双周报专栏的第 6 期，我们将通过这一专栏，定期介绍香山的开源进展，希望与大家共同学习，一起进步。欢迎大家通过公众号后台留言的方式与我们交流！

我们在这两周对时序进行进一步优化，并修复了一些因时序优化带来的 bug。RISC-V 特权手册近日更新到 1.12，我们及时进行了跟进。另外，我们也将 Spike 纳入到 Difftest 框架中，现在香山可以和 Spike 进行 Difftest 验证了。

<!-- more -->
## 近期进展

### 前端

* **Fetch 部分（包括 IFU/ICache/PreDecode/IBuffer）时序优化，**已基本达标
* **添加 ICacheMainPipe 简化 ICache 的 Probe 和 Release 处理逻辑**
* **解决 PreDecode 时序优化带来的功能问题**
* **解决 IFU 写回逻辑因时序优化导致分支误预测数上升的问题**

### 后端

* **为优化时序，对部分 CSR 的更新进行了加拍处理，**后端时序已基本达标
* **更新到特权手册 1.12（的部分内容），**同时再次检查了 CSR 的更新逻辑，并与 Spike 实现进行对比，具体查看 [PR#1301](https://github.com/OpenXiangShan/XiangShan/pull/1301) 等
* **重构了硬件性能计数器框架的设计，**统一了所有计数器的生成逻辑

### 访存子系统

* **L1D 内部时序优化，**对 refill 和 probe 更新 DCache 的操作进行了加拍
* **优化了 L1D writeback queue 的入队检查逻辑，**现在 writeback queue 可以尝试将更多请求合并到同一项中，同时入队检查的时序也得到了优化
* **为 TLB 增加了 fast_miss 信号，**因为 SRAM 部分的命中逻辑延迟较高，fast\_miss 只关心寄存器全相联部分的结果，用于 Load 流水线的快速唤醒
* **优化了 PTW Filter 的去重逻辑，**并增加了一拍，将去重逻辑拆成两拍
* **修改了 PMA/PMP 的参数传递逻辑，**增加了内存映射版本的 PMA 模块，供 DMA 等外设使用
* **修正了软件预取逻辑**

### HuanCun 子模块

* **L2/L3 内部时序优化，**已基本达标
* **完善了对 ecc 的支持**
* **修复多 bank 情况下的性能 bug**
* **修复了 sinkC 模块 buffer 泄漏问题**

## 后记

香山开源处理器正在火热地开发中，我们将通过香山双周报专栏定期地同步我们的开源进展。感谢您的关注，欢迎在后台留言与我们交流！
