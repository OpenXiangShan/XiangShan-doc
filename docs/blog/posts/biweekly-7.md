# 【香山双周报 7】20211227 期

欢迎来到我们的双周报专栏。本次是香山双周报专栏的第 7 期，我们将通过这一专栏，定期介绍香山的开源进展，希望与大家共同学习，一起进步。欢迎大家通过公众号后台留言的方式与我们交流！

<!-- more -->
## 近期进展

### 前端

* 支持了在奇偶校验发生错误时指令 Cache 访问报 access fault
* 添加分支预测指导的对 L2 的指令预取

### 后端

* **重点关注了异常等原因冲刷流水线的时序情况**，由于出现频率降低且涉及多个距离较远的模块，我们进行了加拍处理
* **优化了 Dispatch 阶段对 LSQ 表项的分配逻辑**，将表项的分配与实际的数据存储、标志位更新解耦，让 LSQ 的分配逻辑时序变得更为宽松
* **支持 LUI + LOAD 类型的操作数旁路**，LOAD 指令的基地址可以直接通过立即数计算得出，不需要等待 LUI 执行结果
* **Trigger Module 实现基本功能，**同时支持在 debug mode 下与 Spike 进行差分验证 difftest

### 访存子系统

* **优化了 L1D load miss 时请求 MSHR 的逻辑。**新版本中，MSHR 请求结果的使用从 load\_s2 移动到 load\_s3，来规避之前版本中产生 MSHR 请求结果的路径过长的问题
* **优化了 sbuffer 的数据写入逻辑**
* **完善了 ecc 错误处理通路的实现。**添加了新的自定义 CSR 寄存器，以为软件侧提供更多的错误信息

### HuanCun 子模块

* **完善了对 DMA 请求的支持**
* **支持指令预取**

## 评估

我们采用 SimPoint 对程序进行采样，基于我们自定义的 Checkpoint 格式制作检查点镜像。SPEC 使用 gcc 10.2 进行编译，优化选项为 O2，指令集是 RV64GCB。**我们使用 12.15 号版本的香山处理器（缓存大小配置为 128KB L1 ICache + 128KB L1 DCache + 1MB L2 + 6MB L3），在仿真环境下运行了 SPEC06 片段，使用 DRAMsim3 模拟 CPU 在 2GHz 情况下 DDR4-2400 内存的延迟**。
