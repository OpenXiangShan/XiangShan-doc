# 【香山双周报 24】20230227 期

欢迎来到我们的双周报专栏。本次是香山双周报专栏的第 24 期，我们将通过这一专栏，定期介绍香山的开源进展，希望与大家共同学习，一起进步。近期，昆明湖开发在稳步推进，向量定点指令已通过简单测试并开始添加浮点向量指令；紧耦合 L2 缓存及 Load 队列拆分开始性能调优，Load 通路加宽已完成调试；新指令缓存别名问题也已解决。此外，我们还新增了常量参数自动寻找工具。欢迎大家通过公众号后台留言的方式与我们交流！

<!-- more -->
## 近期进展

### 前端

* 解决新设计下 ICache 别名问题
* 初步实现 ICache 细粒度 bank 划分，减少取指功耗
* 初步实现新版基于 Runahead 机制的 Oracle 预测器

### 后端流水线

* 初步实现向量指令拆分单元
* 初步支持单指令拆分 uop 的 ROB 压缩，一条原始指令只占用一个 entry
* 初步实现 vrgather 运算单元
* 实现向量 f2s 等 move 指令
* 实现向量整数运算功能单元（除定点数相关、reduction 和 mask 指令）

### 访存单元

* LQ 拆分功能测试通过，开始性能调优
* 完成 128 bit load 数据通路的设计
* 修改 L2，尝试为 L1 提供自定义 Hint Channel
* 定位 Dcache 替换算法更新时机的 bug，测试几种新的替换算法更新时机设计

### 缓存系统

* 接入南湖香山，通过所有 SPEC 检查点测试
* 正在进行性能优化：

    * 添加目录分 bank 进行读写设计
    * 修复预取、替换算法的性能 bug
    * 分析 Release 带 Data 的情况对性能的影响

### 杂项

* **工具开发**

    * 设计了一个自动参数求解器，用于寻找一个表现较好的常量参数

## 后记

香山开源处理器正在火热地开发中，新的功能与新的优化在持续添加中，我们将通过香山双周报专栏定期地同步我们的开源进展。感谢您的关注，欢迎在后台留言与我们交流！
