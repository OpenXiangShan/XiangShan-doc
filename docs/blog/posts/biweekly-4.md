# 【香山双周报 4】20211115 期

欢迎来到我们的双周报专栏。本次是香山双周报专栏的第 4 期，我们将通过这一专栏，定期介绍香山的开源进展，希望与大家共同学习，一起进步。欢迎大家通过公众号后台留言的方式与我们交流！

<!-- more -->
## 近期进展

### 前端

* **修复预译码的 bug：**

    * 解决了某些情况下 jal 指令预测错误未检出的问题
    * 解决了跨行取指请求是 false hit 的部分情况下取指错误的问题
    * 解决了 false hit 且取指块大小为 34 Byte 时取指出错的问题

* **优化 ICache 物理设计**，使用 bank interleaving 方法代替两读口 SRAM 的功能
* **修复 MMIO 取指通路的 bug：**

    * 取消 MMIO 条件下的推测路径，避免发送错误的取指请求到 ICache 的情况
    * 在后端传来异常信号时冲刷 IFU 内的相应状态

* **优化分支历史实现方式**，分支历史寄存器改为指针索引的 circular buffer 实现，为 TAGE 类预测器存储折叠历史，显著降低预测路径时延
* **优化 BPU 时序**，把 uBTB 的关键路径放到优先选择器的最后一级

### 后端

* **添加了全新的 SRT16 浮点除法与开方部件**，在部分 SPEC 浮点片段上有明显的 IPC 提升

    * 浮点运算部件全部开源在 FuDian 仓库中，我们已经不再依赖于 hardfloat 了

### 访存子系统

* **优化了 TLB 的时序**，涉及到物理页的产生逻辑优化，以及异常检查和命中检查逻辑的分离等
* **DTLB 到 L2TLB 再加拍**，增加一个 Repeater，弥补物理距离带来的线延迟
* **修复 L2TLB 的 Page Table Cache 的 bug**，解决了对 PipeLineConnect 的错误使用带来的卡死问题
* **优化了 PMP 的判断时序**，从一连串的 Mux 改成并行的 Mux

### HuanCun 子模块

* **完成 Tilelink 测试框架基本功能开发**，借此发现并修复了若干关于请求打断的 bug
* **修改通道的逻辑与写法**，支持任意拍数延迟的 SRAM
* **完善 Put 请求的实现**

忙碌的两周又过去了，这两周中，除了 bug 修复以外，我们最主要的工作是时序优化。目前我们仍在向着 11 月底时序收敛的目标稳步推进。

## 后记

香山开源处理器正在火热地开发中，我们将通过香山双周报专栏定期地同步我们的开源进展。感谢您的关注，欢迎在后台留言与我们交流！
