# 【香山双周报 23】20230213 期

欢迎来到我们的双周报专栏。本次是香山双周报专栏的第 23 期，我们将通过这一专栏，定期介绍香山的开源进展，希望与大家共同学习，一起进步。欢迎大家通过公众号后台留言的方式与我们交流！

<!-- more -->
## 近期进展

### 前端

* **昆明湖开发**

    * FDIP 初步可用
    * 修复新版设计中 ICache mutli-hit 问题

### 后端流水线

* **昆明湖开发**

    * 推进乱序流水线的重构工作
    * 完成向量指令拆分单元对首条指令的支持
    * 完成向量浮点除法器 F64、F32 的设计和验证

### 访存单元

* **昆明湖开发**

    * 推进 LQ 拆分工作
    * L1 预取框架迁移到主分支
    * 完成向量 store 数据通路，向量 load 的数据通路修改正在进行中
    * 推进和优化向量访存 uop 拆分和调度的设计
    * 设计了 L2 - L1 之间的自定义 Hint Channel，用于优化 load miss latency
    * 实现 Fake L1 TLB，对 MMU 单元进行性能分析

### 缓存系统

* **昆明湖开发**

    * 成功通过 tl-test 测试框架在双核下的测试
    * 新缓存接入南湖版香山，运行 workload 进行测试
    * DRRIP 替换策略基本实现完成，开始调试

### 杂项

* **昆明湖开发**

    * 新增常量注入工具 Constantin，允许仿真器运行前修改 RTL 内常数值而无需重新编译

## 后记

香山开源处理器正在火热地开发中，新的功能与新的优化在持续添加中，我们将通过香山双周报专栏定期地同步我们的开源进展。感谢您的关注，欢迎在后台留言与我们交流！
