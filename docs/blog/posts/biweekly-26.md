# 【香山双周报 26】20230403 期

欢迎来到我们的双周报专栏。本次是香山双周报专栏的第 26 期，我们将通过这一专栏，定期介绍香山的开源进展，希望与大家共同学习，一起进步。近期，昆明湖研发稳步推进，前端修复了一系列 bug；后端完成了更多组件重构，实现了 ROB 压缩；访存单元持续推进性能调优，实现 strided、indexed 向量访存支持；缓存系统实现了新预取算法并持续性能调优。南湖架构已经稳定。欢迎大家通过公众号后台留言的方式与我们交流！

<!-- more -->
## 近期进展

### 前端

* 修复 ICache 替换算法 vidx 在低位截断导致的性能 bug
* 修复 ICache 使用的 Tilelink master id 范围 bug
* 修复预取队列与 ICache 主流水线交互 bug
* 修复 ITTAGE 在访存 replay 场景下使用错误信息更新的性能 bug

### 后端流水线

* 完成单指令拆分多个 uop 的 ROB 压缩
* 完成后端流水线中访存相关通路的重构
* 整型除法模块基本完成（SRT16 & SRT4 算法），支持多种位宽

### 访存单元

* 评估 LQ 拆分性能，增大容积评估拆分效果
* 评估不同的 store 预取效果
* 推进 Sector TLB 的实现和调优
* 向量 Load strided 和 index 基本完成，增加单元测试
* Dcache miss queue 入队逻辑拆分为两拍以优化时序

### 缓存系统

* 进行性能调优：

    * 优化 AcquirePerm Miss 的处理逻辑，并进行性能评估
    * 移除了请求的 set 阻塞，目前正在调试中
    * 重构请求仲裁逻辑，优化 Reqest Buffer 发射条件，正在实现中

* 与后端一起评估物理实现，优化关键路径
* 调研 CHI 总线，并编写了测试框架 CHI-Test
* IPCP Prefetcher 基本实现完成，准备接入测试

## 后记

香山开源处理器正在火热地开发中，新的功能与新的优化在持续添加中，我们将通过香山双周报专栏定期地同步我们的开源进展。感谢您的关注，欢迎在后台留言与我们交流！
