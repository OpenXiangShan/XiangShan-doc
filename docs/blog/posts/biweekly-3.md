# 【香山双周报 3】20211101 期

欢迎来到我们的双周报专栏。本次是香山双周报专栏的第 3 期，我们将通过这一专栏，定期介绍香山的开源进展，希望与大家共同学习，一起进步。欢迎大家通过公众号后台留言的方式与我们交流！

<!-- more -->
## 近期进展

### 前端

* **恢复了从 MMIO 空间取指的通路**，并且支持与参考模型进行正确性对比
* **修复 IFU 的 bug，**解决了在第一个 cache 行 miss，第二个 cache 行触发异常的情况下请求无法送到 MissQueue 的问题
* **优化 FTB 面积利用效率**，在每个 entry 里，减少一条 branch 专用的存储位置，让 jump 专用的存储位置和 branch 共享
* **修复预译码的 bug**，解决了发生 page fault 的 pc 是一个取指 block 的首地址的时候，无法挂上 page fault 的问题
* **修复 IFU 的 bug**，避免了将发生异常的取指请求也视为 MMIO 请求
* **修复预译码的 bug**，解决了跨页指令页错误无法挂上 page fault 的问题

### 后端

* **新增了可配置的硬件计数器框架**，支持软件对计数器的动态配置
* **将 Load/Store Queue 改到了 Dispatch2 这一级流水级入队**，一方面减少了不必要的提前占用、提高了各项的利用率，另一方面也更有利于物理设计阶段进行布局
* **添加了 FADD/FMUL 功能部件的流水级**，经过后端时序评估确认后，我们恢复了 FMA 功能单元的流水级，不再使用手动加拍的方式模拟 FMA 延迟

### 访存子系统

* **启用新的 DCache 设计**，新的设计将 DCache 中的主流水线拆分成支持不同功能的子流水线，来保证 refill 等关键操作尽快完成。同时，新的 DCache 设计删除了冗余的缓冲区来优化面积
* **增加了对 Svinval 扩展的支持**，可以通过修改自定义 CSR 寄存器来动态控制
* **增加了对 ASID 的支持**，并且可以启动新版支持 ASID 的 linux 内核
* **添加了 load - load 违例的检查逻辑**，在发生 load - load 违例时会从取指处重新开始执行
* **添加了自定义 Cache 控制指令**
* **优化了 TLB 的时序**，涉及到命中检查和例外检查，并在 ITLB 和 L2TLB 之间增加了一拍，弥补物理距离过远带来的线延迟
* **优化了 L2TLB 的时序**，涉及到 L2TLB 的 ecc 检查，每 64bits 作为一个 ecc 块，而不是整体作为 ecc 块
* **优化了 PMA 的实现方式**，采用类 PMP 的形式实现，利用了 M 态自定义 CSR 寄存器和 PMP 的保留位，可以通过 CSR 读写指令实现对 PMA 的读写
* **将物理地址的宽度减少到了 36 bit**，减少了一定的资源消耗。由于物理地址位宽完全可配，所以这一修改仅是针对南湖流片版本进行的，后续会根据项目需求调整实际配置情况
* **简化了软件预取的译码逻辑**
* **修正 Store Queue 指针更新逻辑**，在有大量外部中断时能正确进行 MMIO 访存操作

### HuanCun 子模块

* **更新 L2/L3 Crossbar 组织形式**，去除冗余的数据通路从而优化时序面积
* **合并 Client Dir**，减少在多核情况下的面积占用
* **开发 TLC-test 测试框架（WIP）**，目前完成了主要部件的编写，并通过它修复了 2 个与 Put 相关的功能 Bug
* **修复了随机替换算法的使用 Bug**，避免 Client Dir 替换时永远挑选同一个 way
